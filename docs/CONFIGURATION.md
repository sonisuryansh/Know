# Extension Configuration & Settings

Know settings can be customized in VS Code Settings (`Ctrl+,` on Windows/Linux or `Cmd+,` on macOS) by searching for **Know**.

---

## ⚙️ Available Settings

| Setting Key | Type | Default | Description |
|---|:---:|:---:|---|
| `know.defaultDurationMinutes` | `number` | `35` | Default focus session target duration in minutes for new sessions. |

---

## 🔄 Backward Compatibility
If you previously configured `devFocus.defaultDurationMinutes`, Know will automatically recognize your setting as a fallback without losing your custom duration.
