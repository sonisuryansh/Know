# Command Palette Reference

All Know commands can be executed via the VS Code Command Palette (`Ctrl+Shift+P` on Windows/Linux or `Cmd+Shift+P` on macOS).

---

## ⌨️ Registered Commands

| Command Title | Identifier | Description |
|---|---|---|
| **Know: Start Focus Session** | `devFocus.startSession` | Opens interactive wizard to start a focus timer or select a task |
| **Know: Quick Add Task to Inbox** | `devFocus.quickAddTask` | Captures an idea or task directly to Inbox from anywhere |
| **Know: Create Task from Current File** | `devFocus.createTaskFromCurrentFile` | Pre-fills a new task linked to the active editor document |
| **Know: Start Focus on This File** | `devFocus.startFocusOnFile` | Starts a focus session named after the active editor filename |
| **Know: Link Current File to Task** | `devFocus.linkCurrentFile` | Connects the active editor document to an existing task |
| **Know: Create New Task** | `devFocus.createTask` | Opens the comprehensive task creation modal |
| **Know: Pause Focus Session** | `devFocus.pauseSession` | Pauses the currently running focus timer |
| **Know: Resume Focus Session** | `devFocus.resumeSession` | Resumes a paused focus timer |
| **Know: Finish Focus Session** | `devFocus.finishSession` | Completes active session, logs notes, and updates task status |
| **Know: Import GitHub Repository** | `devFocus.importGitHubRepo` | Clones a GitHub repository URL into a local directory and binds as project |
| **Know: Associate Current Workspace as Project** | `devFocus.associateCurrentWorkspace` | Connects the currently open VS Code workspace to Know |
| **Know: View Focus Hub** | `devFocus.viewFocus` | Focuses and opens the Know sidebar view |
| **Know: View Productivity Stats & Heatmap** | `devFocus.viewStats` | Focuses the Know sidebar on statistics |
| **Know: Open Focus Hub in Editor Tab** | `devFocus.openInTab` | Opens the full Know dashboard inside an editor tab |

---

## 🖱️ Context Menu Shortcuts

- **Editor Context Menu:** Right-click inside any code file $\rightarrow$ **Know: Start Focus on This File** or **Know: Create Task from Current File**.
- **Explorer Context Menu:** Right-click any file in the VS Code File Explorer $\rightarrow$ **Know: Start Focus on This File** or **Know: Create Task from Current File**.
