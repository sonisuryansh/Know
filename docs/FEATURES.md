# Know — Features Overview

**Know** brings essential developer focus and workflow tools directly into Visual Studio Code.

---

## 🎯 1. Smart Focus Timers & Stopwatch
- **Interval Presets:** `25m` (Pomodoro), `45m`, `60m`, and `90m` standard durations.
- **Custom Duration Mode:** Set any target duration in minutes.
- **Open-Ended Stopwatch:** Count-up stopwatch mode (`0` target minutes) for exploratory research and ad-hoc coding.
- **In-Session HUD:** Live countdown clock, real-time progress bar, and project context card.
- **Live Session Controls:** Pause, resume, extend by `+5m`, or finish sessions with summary notes.
- **Status Bar Integration:** Real-time countdown or stopwatch ticker in the VS Code status bar.

---

## 📋 2. Frictionless Task Management
- **Instant Quick Capture:** Single-key `Enter` submission from the top Inbox bar.
- **Today's Focus Queue:** Curate 3–5 high-priority goals for your current working session.
- **Priority Tiers:** Tag tasks as `Low`, `Medium`, `High`, or `Urgent`.
- **Work Categories:** 11 built-in categories (Features, Bug Fixes, Refactoring, Docs, etc.).
- **Active Editor File Linking:** Associate open editor files directly with tasks (`📄 File`). Click to open the linked file instantly.
- **Task Attempt History:** Automatically logs every focus attempt, duration, and session notes under the task.

---

## 📁 3. Project Management
- **Group Tasks by Scope:** Separate personal projects, client repositories, and learning modules.
- **Workspace Folder Association:** Link local filesystem directories and launch workspaces in VS Code with one click.
- **Git Metadata Binding:** Displays connected Git repository URLs and active branch names.
- **Progress Tracking:** Automatic task completion percentage bars and total accumulated focus time.

---

## 🐙 4. GitHub & Git Integration
- **Direct GitHub Clone:** Clone repositories via HTTPS, SSH, or `owner/repo` short syntax.
- **Folder Safety Checks:** Automatically verifies destination directories to prevent accidental file overwriting.
- **Workspace Association:** Auto-detects local Git remotes and active branches in open workspaces.

---

## 📊 5. Statistics & 52-Week Activity Heatmap
- **52-Week Activity Heatmap:** Visual 365-day calendar grid tracking daily focus minutes across 5 intensity levels.
- **Streak Tracking:** Computes current active day streak and all-time longest streak.
- **Time Distribution:** Visual progress bars for category and project time allocations.
- **Session History Log:** Chronological record of completed sessions with durations and user notes.

---

## 🎨 6. Native VS Code Theme Compliance
- Built 100% on VS Code CSS variables.
- Seamlessly adapts to Dark+, Light+, High Contrast, and community themes.

---

## 🔒 7. 100% Local & Private
- Zero telemetry and zero cloud accounts.
- All tasks, projects, sessions, and stats are saved locally in VS Code `globalState`.
- Complete JSON export and import capabilities.
