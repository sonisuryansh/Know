# Project Management in Know

Projects in Know group related tasks, measure cumulative development time, and link directly to local workspace directories and Git repositories.

---

## 📁 Why Use Projects?
- **Scope Organization:** Group tasks by initiative (e.g. *Personal Apps*, *Company Work*, *Open Source Libraries*, *Learning Practice*).
- **Time Aggregation:** Know automatically calculates the total minutes spent focusing on each project.
- **Progress Tracking:** Shows real-time completion percentage bars based on completed versus total tasks.

---

## 🛠️ Project Features

### 1. Visual Customization
- Choose custom emoji icons (🚀, 💼, ⚡, 🐙, 📦, 💡, 🔧, etc.) and color accents to quickly distinguish between projects in the sidebar.

### 2. Workspace Directory Association
- Link a project to a local folder path on your computer.
- Click **Open Folder in VS Code** on any project card to open that project workspace immediately (`vscode.openFolder`).

### 3. Git Repository Connection
- Displays connected Git repository URLs (e.g. `https://github.com/user/repo`).
- Auto-detects and displays the current Git branch (e.g. `main`, `feature/auth`).

---

## ➕ Creating a Project
1. Open Know $\rightarrow$ Click the **Projects** tab.
2. Click **+ New Project**.
3. Enter Project Name, Category, Icon, Color, and optional local directory / repository URL.
4. Click **Create Project**.
