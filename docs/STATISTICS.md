# Productivity Statistics & Heatmap in Know

Know calculates and visualizes your actual coding focus activity across days, weeks, and months.

---

## 📅 52-Week Activity Heatmap

Know includes a visual 365-day calendar grid (similar to GitHub's contribution graph) that maps daily focused minutes:

| Intensity Level | Minutes Focused | Description |
|:---:|:---:|---|
| **Level 0** | `0 mins` | No recorded focus sessions |
| **Level 1** | `1 – 29 mins` | Light focus activity |
| **Level 2** | `30 – 59 mins` | Moderate focus session |
| **Level 3** | `60 – 119 mins` | Substantial deep work |
| **Level 4** | `120+ mins` | Intensive focus day |

---

## 🔥 Day Streaks
- **Current Streak:** Consecutive days with recorded focus activity ending on today or yesterday.
- **Longest Streak:** All-time record for consecutive active coding days.

---

## 📈 Period Totals
- **Today:** Focus minutes, completed tasks, and session count.
- **This Week:** Cumulative minutes recorded across the current 7-day window.
- **This Month:** Cumulative minutes for the current calendar month.
- **All-Time:** Total accumulated focus hours and completed task count.

---

## 🥧 Time Distributions & History
- **Category Distribution:** Visual progress bars displaying the percentage of time invested in each work category (*Features*, *Bug Fixes*, *Docs*, *Testing*, etc.).
- **Project Breakdown:** Total focus minutes per project.
- **Recent Session History:** Chronological log table showing date, task name, project, duration, and user summary notes.
