## 📖 What is Know?

**Know** is an all-in-one developer productivity workspace built directly into Visual Studio Code. It unifies daily task planning, focus timers, project management, GitHub repository cloning, and coding activity analytics inside your editor so you can work without switching between browser tabs and external apps.

---

## 🚀 Key Capabilities

- **🎯 Smart Focus Timers:** Countdown presets (`25m`, `45m`, `60m`, `90m`), custom durations, or count-up stopwatch mode with live status bar feedback. [Learn more](docs/FOCUS-SESSIONS.md)
- **📋 Frictionless Task Management:** Single-key Inbox capture, prioritized Today queue, work categories, estimated minutes, and active editor file linking. [Learn more](docs/TASKS.md)
- **📁 Project Organization:** Group tasks by project, track completion percentages, link local workspace folders, and launch projects in one click. [Learn more](docs/PROJECTS.md)
- **🐙 GitHub Integration:** Clone and import GitHub repositories directly with automatic folder collision safety checks. [Learn more](docs/GITHUB.md)
- **📊 52-Week Activity Heatmap:** GitHub-style 365-day calendar grid tracking daily focus minutes, streaks, and category breakdowns. [Learn more](docs/STATISTICS.md)

---

## 💡 Why Know?

- 🚫 **No Context Switching:** Manage tasks and timers directly in the VS Code sidebar or editor tab.
- 📄 **Context-Aware File Linking:** Associate open editor files directly with tasks (`📄 File`) for one-click resumption.
- 🎨 **100% Native Theme Adaptive:** Seamlessly matches your active VS Code theme (Dark+, Light+, High Contrast).
- 🔒 **100% Private & Offline:** Zero telemetry, no cloud accounts, and all data stored locally on your machine. [Read privacy policy](docs/PRIVACY.md)

---

## 📦 Installation

1. Open VS Code.
2. Open the Extensions view (`Ctrl+Shift+X` or `Cmd+Shift+X` on macOS).
3. Search for **Know** by **sonisuryansh**.
4. Click **Install**.
5. Click the **Know** icon in your Activity Bar to open your workspace.
